说一个市场传言（我个人并不认同此为造假)

☞“收入回转结构”（revenue roundtripping）是一种被市场传言的存在于微软、英伟达与 OpenAI 之间的特殊收入关系。但目前并没有公开的确切信息明确其具体形式和运作机制，更多是基于市场现象和各方关系的一种推测。以下是相关分析：

- 微软与 OpenAI：微软是 OpenAI 的最大外部股东，已向 OpenAI 投资超过 130 亿美元。根据协议，微软有权获得 OpenAI 未来利润的 75%，直至其本金投资得到全额偿还。同时，OpenAI 每年需向微软支付 10 亿美元的云服务器租赁费用，此外，OpenAI 的发展也助推微软收入上涨。

- 英伟达与 OpenAI：英伟达为 OpenAI 提供训练人工智能模型所需的高性能 GPU 芯片。随着 OpenAI 等人工智能企业对算力需求的不断增长，英伟达的 GPU 产品销量大幅提升，营收也随之增加。例如，英伟达向 OpenAI 提供 DGX 系列超级计算机等硬件产品，2024 年英伟达 CEO 黄仁勋还亲自将全球首台超级计算机 DGX H200 交到 OpenAI CEO 手中。

- 微软与英伟达：微软是英伟达的重要客户，会购买英伟达的 GPU 用于自身的数据中心建设和 AI 业务发展。同时，英伟达与微软在云计算、人工智能等领域也有合作。此外，有观点认为，微软通过投资 OpenAI，间接影响了英伟达 GPU 在人工智能领域的市场需求，因为 OpenAI 对 GPU 的大量采购，推动了英伟达 GPU 业务的发展，进而使英伟达获得更多收入，而英伟达又可能将部分收入用于购买微软的云计算服务或其他产品，形成一种收入的循环流动。

不过，“收入回转结构” 目前只是一种市场猜测，其真实性和具体内涵尚未得到官方证实。像 CoreWeave 与微软、英伟达关系密切，也被传卷入该结构中，这一传闻加剧了投资者对 CoreWeave 真实收入结构和可持续性的质疑。

☞说下我得解读，微软投资 open ai 首先是看好人工智能的发展，微软租售算力给投资的 open ai 也是正常商业行为，因为本身就是算力中心，照顾自家生意罢了，符合正常逻辑。

微软是英伟达大客户，英伟达有相关业务需要，为了维持大客户关系，租用其算力，也是情理之中。

结论

☞这里必然是有商业利益，互利互惠。只要业务是真实的，投资是真实的，研究的大模型是真实的，英伟达的市场需求和利润是真实的，那一切有什么问题呢？

☞市场最应该关心的，应该还是人工智能的未来发展和全球对算力的实际需求。
