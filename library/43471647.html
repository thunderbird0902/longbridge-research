OpenAI、Anthropic 作为全球两大顶级闭源大模型厂商，虽未上市，但属于美股 AI 板块的 “定价锚”，直接决定微软、谷歌等 AI 生态股的估值中枢。两家企业持续亏损，并非商业模式存在缺陷，而是 AI 产业早期战略性烧钱筑壁垒的必然阶段，其亏损来源清晰，且暗藏明确的长期盈利逻辑。

第一，高额基座模型迭代训练成本，构成刚性前置亏损。大模型的能力壁垒来自持续、高强度的研发迭代。OpenAI 持续投入数十亿美元迭代 GPT-4、GPT-5 多模态体系，覆盖文本、图像、视频、逻辑推理、智能体能力；Anthropic 主打高安全性、超长文本、企业级稳定推理，深耕政企高端场景，同样保持全年高强度研发与模型训练投入。

模型预训练、参数迭代、对齐优化均属于超高前置资本开支，投入大、周期长、无法通过短期营收对冲，因此账面必然持续亏损。这类亏损并非经营低效，而是为了长期技术垄断壁垒支付的必要成本。

第二，C 端免费推理引流，产生持续性边际亏损。两家头部模型企业均采用基础功能免费的 C 端策略，市场普遍误区认为：免费是为了抓取用户聊天数据训练模型。

真实逻辑完全不同：普通用户碎片化闲聊数据，对基座大模型迭代价值极低，且全球隐私合规严格限制用户数据商用训练。免费模式的真正核心目的只有三点：第一，抢占全球用户心智，完成全民 AI 市场教育；第二，积累海量潜在企业客户；第三，收集真实场景反馈与错误案例，用于 RLHF 人类偏好对齐与模型优化。

每一次免费用户的对话与生成，都会消耗真实算力，形成持续的边际亏损。站在美股投资视角，这是典型的 “短期让利换长期垄断”：短期牺牲利润换全球认知壁垒、使用习惯壁垒与场景数据壁垒，待行业成熟期完成变现闭环。

三、美股大模型软件层修正版盈利逻辑（纯软件专属）

市场过度悲观的核心误区，是认为 AI 软件企业会永久亏损。结合美股商业化节奏与产业迭代规律，AI 大模型的盈利是成本下行 + 壁垒成型 + 双端变现落地的确定性趋势，四大核心逻辑清晰可落地。

1、行业整体 Token 推理成本持续下行，逐步收窄亏损缺口。随着行业推理架构优化、模型轻量化、稀疏化技术普及、算力资源集约化调度，全市场单位 Token 的推理成本持续下降。虽然软件企业无法摆脱算力刚性成本，无法像互联网一样实现零边际成本，但成本的系统性下行，会让通用场景的边际亏损持续收窄，为盈利拐点奠定基础。

2、免费烧钱阶段接近尾声，行业心智壁垒已定型。经过多年普及，全球用户 AI 使用习惯已经完全成熟，OpenAI、Anthropic 的品牌认知、模型体验、生态壁垒已经形成寡头格局。企业无需再依靠大规模免费算力补贴换取市场认知，未来将逐步收缩低效免费流量，减少无效亏损，优化整体盈利结构。

3、B 端企业付费是软件层核心、最确定的盈利主线。美股 AI 软件的终极盈利支柱绝非 C 端散户，而是海外政企、商业机构、云端企业客户。OpenAI、Anthropic 的核心价值在于高精度、高稳定、高安全的企业级模型能力，可通过 API 按量调用、企业年度订阅、私有化部署、行业定制解决方案持续变现。

B 端业务具备高客单价、高复购、高稳定性、低波动的特征，也是微软 Azure、谷歌云 AI 业务增长的核心驱动力，是美股 AI 软件板块唯一具备长期确定性的收入来源。

4、C 端分层变现落地，补齐软件营收短板。未来 C 端将彻底告别全员免费模式，形成成熟分层体系：高端用户通过 ChatGPT Plus、Claude Pro 等会员订阅，解锁高阶推理、多模态生成、超长文本、极速算力等增值服务，贡献高毛利收入；普通用户通过轻量化广告、内容推荐实现流量变现，抵消基础推理成本。C 端从 “纯亏损流量” 转变为 “增量营收资产”。
