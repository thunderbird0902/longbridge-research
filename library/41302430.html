$晶泰控股 (2228.HK)$晶泰控股(02228.HK) （晶泰科技 / XtalPi）沽空作用研究报告

问题：过去约 8–9 个月 $晶泰控股 (2228.HK) 股价持续调整、大幅波动，沽空在其中起了多大作用？

方法：Longbridge CLI 取数（320 根日线 + 周度沽空持仓 + 日度沽空成交 + 同业/指数基准）→ 5 个独立量化镜头并行计算 → 逐镜头对抗式复核 → 综合。原始数据与脚本见本目录。

窗口：峰值收盘 **14.87 HKD（2025-10-01；盘中高 15.12 @10-05）→ 8.24 HKD（2026-05-28）= −44.6%**。

日期：2026-05-31 ｜ 立场：以证据为准，不做无谓的"各打五十大板"。

一句话结论

沽空是"次要放大器 + 症状"，不是主因。 这轮下跌的本质是一轮 +223% 抛物线行情（PE ~258）的均值回归，叠加 HK 科技/AI 制药板块系统性 de-rating 和反复增发/解禁的筹码供给压力。5 个独立镜头复核后的"沽空贡献分"集中在 13–40/100，共识 ≈ 27；折算 沽空对跌幅的贡献约 15–20%（区间 10–25%），且集中在 2026 年的第二段下跌与压制反弹/波动上，对 2025/10–12 的初始暴跌贡献近乎为零。

四、沽空到底起了多大作用（核心）

4a. 日内沽空"流量" — 机械打压假说被否定

机械打压需要明显负的当日相关。数据相反：

当日 corr(沽空占比， 收益) = +0.016，R²≈0.0002，OLS 斜率 +0.007（t=0.16）—— 解释力≈0，且方向相反。

领先相关为正：r[t+1]=+0.20、r[t+2]=+0.28、r[t+3]=+0.23 —— 高沽空日领先上涨，是典型"逢强做空/沽空率均值回归"，与"打压"相反。（多重检验校正后仅 k=+2 显著，已披露。）

高沽空日是缩量（−0.35）、低波动（| 收益 | 相关 −0.19）日 —— 机会性，非进攻性。

窗口内最大单日暴跌（2026-01-14，−10.7%）是低于均值的沽空日（占比 0.041 vs 均值 0.146）；12/12 最差交易日都由盘中而非跳空驱动；跌日 vs 涨日沽空占比统计上无差异（Welch t=0.48）。

结论：日内沽空"跟随"价格，不"驱动"价格。 贡献分 13（已复核）。

4b. 沽空"存量"（持仓）— 领先还是滞后？→ 滞后/趋势跟随

周度 ΔSI vs 当周收益 = +0.46（逢强加空）；vs 下周收益 ≈ +0.06（t=0.49，≈0） —— 无领先预测力（聪明钱式领先应为负）。

第一波（2025-07–08）：SI 1.1%→4.0%，而价格还在涨 +80%；峰值 SI 出现在价格顶部前 ~5 周 → 空头过早被反向碾压。

回补段（2025-10–11）：价格已自顶部跌 ~35% 后，SI 反从 3.3% 砍到 2.15% —— 反应式获利了结（"回补预示进一步走弱"的子论断统计脆弱，定为不确定）。

第二波（2025-11–2026-05）：SI 重建至纪录 7.39%/3.18 亿股，完全发生在见顶后下跌途中（波内同期相关 +0.66）—— 在已破位的图形上加压。

拥挤/逼空：days-to-cover 升至 ~4.8–5.9 天（逼空风险通常需 >10）—— 拥挤、退出慢，但未被逼；空头账面约 +19–25% 浮盈（建仓多在 9–13 vs 现价 8.24）→ 强制回补压力低，可以慢慢扛。贡献分 40（已复核）。

4c. 放大 / 压制反弹（给空头的"诚实残差"）

近 1 月顶部（13.97）附近堆起的 7%+ 存量是真实的边际供给；见顶后 SI 水平与价格水平相关 −0.75，与"空头加压、压制反弹"一致。但"在下跌途中加空"既可解释为因果、也可解释为动量/症状。净评：真实但少数派的次级放大作用。

4d. 对"波动率"的作用

反直觉：沽空未放大波动 —— corr(沽空占比， | 收益 |)=−0.19（重仓沽空日反而更平静），盘中（非跳空）解释 ~88% 的收益方差。真正的波动来自实钱派发与情绪反转。沽空对波动的清晰印记是潜在的、向上的逼空风险（如 2026-05-26 因延长锁定 +9%），是上行尾部而非下行。

五、数据验证 caveats（界定置信边界）

初始暴跌"流量盲区"：日度沽空成交数据始于 2025-12-29，距峰值已 ~3 个月 —— 跌幅的 81%（14.87→9.50）发生在任何成交流量数据之前。4a/4d 仅适用于 −13% 的第二段，初段只能靠周度 SI 推断（而那段 SI 在回补）。

周度 SI 滞后 ~2 周（SFC 周五快照、~9–10 个工作日后公布），会让空头"看起来更滞后"；但≈0 的下周预测相关对此稳健。

HK 沽空成交被做市商污染：~15–18% 的沽空占比是市场常态（只有持续偏离才是信号）。2228 约 78% 的总沽空流量从未变成净持仓（毛 8.51 亿 vs 净增 ~1.85 亿）—— 多为窝轮/牛熊证/ETF/可转债套利对冲，非方向性看空；且长线缩量时沽空占比会机械抬升（分母效应）。

缺借券成本/利用率数据：无法直接测空头盈亏与逼空压力，"cost"字段是收盘 mark，非真实建仓价 —— 空头浮盈与回补压力是推断非实测。

统计脆弱：n=100 日 / n≈66 周；领先相关 t≈2–2.8（边际）；系统性占比随方法在 60%（对数）~69%（简单）间变动；美股同业仅按日期串对齐（方向性）。

论断置信

七、对持有者的含义（当前无仓、现金不足 1 手）

别把这轮跌主要归咎于空头：它主要是"泡沫回吐 + 板块齐跌 + 筹码供给"，空头是搭车并在第二段边际加速。

空头当前更像上行风险源：7.39% 拥挤 + 浮盈可扛 + ~5 天回补 + 正向催化（延长锁定、DoveTree 里程碑付款、管线进 IND）→ 任何利好都可能触发逼空急拉。

真正要盯的不是沽空、是供给与基本面：后续解禁/配售/可转债转股节奏、DoveTree 收入的可持续性（剔除一次性首付后的常态盈利）、HSTECH/板块情绪。沽空持仓比率见顶回落才是空头认输、底部确认的早期信号。
