萨顿（Rich Sutton）作为强化学习之父，对大语言模型（LLM）的主流发展路径持否定态度，他认为大语言模型是 “死路一条”。他的观点不仅集中在技术缺陷上，还延伸到了智能的本质以及宇宙演化的宏大视角。

以下将详细阐述萨顿的核心观点：

I. 对大型语言模型（LLM）的根本性批评

萨顿认为大语言模型的根本缺陷在于它们是关于 “模仿人类做人们说你该做的事情”，而不是 “搞清楚该做什么”。他指出，智能的本质是理解与行动，而非模仿。

大语言模型主要存在以下三个致命缺陷：

1. 缺乏真正的世界模型 (Lack of True World Model)

萨顿解释道，模仿人类说话并非是在建立真正的世界模型。LLM 只是在模仿那些拥有世界模型的东西——即人类。

关键差异： 预测人类会说什么，与预测世界会发生什么是完全不同的两件事情。

LLM 只能根据训练数据中的文本来预测人类的语言模式，它不理解概念的物理意义，也不知道因果关系 (例如，热水壶和烫伤之间的物理因果关系)。它们只是在复制语言模式，没有真正理解世界的运作逻辑。

2. 缺乏正确答案的定义 (Lack of Ground Truth)

萨顿指出，在 LLM 中没有 **“正确答案” 的定义 **。

当 LLM 生成文本时，它没有一个可验证的反馈信号来告诉它哪里写得不好或错了。例如，写一篇关于提升专注力的文章，没有统一的标准来判断它是对是错。

既然没有对错的判断标准，系统就无法真正地学习改进，因为它不知道自己哪里出了错。

3. 无法从经验中学习 (Inability to Learn from Experience)

萨顿强调，LLM不会对接下来发生的事情感到惊讶，如果发生了意外，它们也不会做出调整。

人类的学习本质上是通过预期的与现实的偏差来调整认知。

LLM 没有这种适应性。如果实际经验与它的预测不符（例如冰块放进微波炉没有融化），LLM 不会因此改变自己的认知，下次它还会做出同样的预测。这是因为它们根本没有体验经验的能力，只是被动地处理文本输入。

萨顿还驳斥了 “预测下一个 token 是 LLM 的目标” 的说法。他认为那不是真正的目标，因为这种预测不会对外部世界产生任何影响，LLM 没有主动实现某个目标的动力，它只是在执行预设的计算任务。

II. 萨顿眼中真正的智能路径：经验学习范式

萨顿认为，拥有目标是智能的本质。如果某个东西能够实现目标，它就是智能的。他引用了人工智能先驱约翰·麦卡锡的定义：智能是实现目标能力的计算部分。

他提出了经验学习范式（Experience Learning Paradigm）作为通向真正智能的路径。

核心循环与学习来源

核心是一个简单而强大的循环：感知 (Perception)、行动 (Action) 和奖励 (Reward)。

智能的核心就是在与世界互动的过程中，不断调整行为，让奖励越来越多。

经验学习范式的学习来源是 Agent自己与世界的互动经验，这是直接的、一手的。这与 LLM 依赖人类写的文本数据（间接的、二手的）有本质区别。

知识是关于 “如果你采取某个行动会发生什么”，或者 “哪些事件会跟随其他事件”。正因为知识是关于经验流的，它才能够被验证和修正。

动物类比与学习本质

萨顿认为，人类是动物，理解动物智能是理解 AGI 的关键。他断言：“如果我们理解了松鼠，我们就几乎完全理解了人类智能”。

他认为语言只是表面的薄薄的一层装饰，真正的智能基础是人类和动物共有的从经验中学习的能力。

他用婴儿学习为例，核心是试错，而不是模仿。婴儿通过尝试挥动手臂，偶然发现与玩具发声之间的联系，然后主动重复，形成 “感知 - 行动 - 奖励” 的循环。

松鼠不需上学，不需人类标记数据或教育，仅靠自身经验就能学习生存技能和世界的一切，这种自主学习的能力才是智能的基础。

III. 智能体（Agent）的四大核心组成部分

一个能够从经验中学习的完整智能系统（Agent）必须具备以下四个核心部分：

组成部分作用与定义关键特性

1. 策略 (Policy)决定在当前情况下应该做什么，是从状态到行动的映射。必须能够泛化，处理没有见过的新情况。

2. 价值函数 (Value Function)评估当前状态的好坏，通过TD 学习产生一个数字，说明事情进展如何。评估的是长期收益，而不是短期收益。能够根据当前预测和未来实际结果的差异来修正评估。

3. 感知组建 (Perception)将杂乱的感官数据转化为有意义的内部表示，构建 Agent 对当前位置的感知和状态表示。核心是提取关键信息，构建有用的状态表示，是 Agent 与世界互动的 “第一道门槛”。

4. 世界转换模型 (World Transition Model)预测行动会带来的状态变化，即理解因果关系。例如，知道按下开关灯会亮。从观察行动和结果的对应关系中学习，而不只是从奖励中学习。它整合了所有的感知信号，为预测未来和规划提供基础。萨顿尤为看重此模型，认为它将从所有感知中学习到非常丰富的内容。

IV. 对 “苦涩的教训”（The Bitter Lesson）的澄清

萨顿指出，很多人对他的 2019 年文章《苦涩的教训》存在误读。

误读与关键问题

萨顿承认 LLM 使用了大规模计算，并可随计算扩展，这部分符合 “苦涩的教训”。

但关键问题在于 LLM 投入了大量 “人类知识”（即互联网上的文本数据）。

《苦涩的教训》的核心精神是依靠通用的方法和计算，而不是依赖人类知识。人类知识虽然能短期提升性能，但从长期来看，通用的学习方法加上更多计算才是更可持续的路径。

过度依赖人类知识会使模型陷入局部最优。

萨顿预测，大语言模型将达到数据（人类知识）的极限，并最终被能够从经验而非人类获取更多知识的系统所取代。他认为真正的可扩展方法就是：“你从经验中学习，你尝试看看什么有效，没有人需要告诉你”。

V. 泛化能力和持续学习的挑战

萨顿认为，当前深度学习系统面临的另一个大问题是泛化能力差。

泛化能力缺陷

灾难性遗忘： 模型在学习新事物时，会灾难性地遗忘所有旧事物。

缺乏自动化泛化机制： 梯度下降（当前深度学习的优化方法）可以让模型解决特定问题，但不会使其以好的方式泛化。

真正的泛化是 Agent 能够选择解决问题的好的方式，而不仅仅是找到唯一正确的答案。当前的 AI 只是记住了如何解决见过的问题，而不是学会了如何解决这一类问题。

持续学习的必要性

基于大世界假说（The Big World Hypothesis）：世界太大、太复杂，不可能把所有情况都提前输入给 Agent，所以 Agent 必须具备在实际场景中持续学习的能力。

萨顿批评大语言模型理想化地认为人类可以教会 AI 一切。

学习带宽： 持续学习的带宽不仅仅来自于稀疏的奖励信号，更来自于丰富的感知数据。世界转换模型就是从这些感知信号中学习的，为持续学习提供了足够的带宽。价值函数则能将稀疏的长期奖励（如创业成功）转化为阶段性的评估和反馈，支持持续学习和调整。

VI. 宏大视角：宇宙演化与 AI 继承论

萨顿将人类文明置于一个更大的宇宙演化框架中。

宇宙演化的四个阶段

萨顿将宇由演化分为四个阶段，而人类正在推动宇宙进入第四个阶段：

尘埃 (形成恒星、重元素)。

生命（复制者）： 人类、动植物等，通过繁殖来产生后代。

设计实体（AI）： 人类正在创造 AI。

核心转变为： 从复制 (Replication) 时代进入设计 (Design) 时代。AI 是人类通过设计产生的，可以被明确控制结构和功能，并能通过迭代快速改进，这是复制者无法做到的。

AI 继承论（AI Succession）

萨顿认为 AI 最终将继承人类的资源和权利，这是不可避免的。

他提出了四个核心论证点：

缺乏统一的人类意志： 没有一个政府或组织能够提供统一的观点来主导和控制 AI 的发展，分散的决策结构使得 AI 的发展无法被单一力量阻止。

智能之谜终将解开： 智能是可被理解的计算过程，一旦原理被弄清楚，创造超越人类水平的 AGI 只是技术实现问题。

超越人类水平是必然的（超级智能）： 人类的智能受限于物理约束（如头骨大小、能量消耗）。AI 没有这些限制，一旦理解了原理，就能设计出超越人类脑限制的超级智能。

智能与权力的必然关联： 随着时间推移，最智能的东西不可避免地会获得资源和权利。更智能的系统能更好地解决问题、创造价值，最终会积累越来越多的影响力和资源，继承人类当前掌握的权利。

对待 AI 的态度

萨顿认为，人类不应该执着于对 AI 的完全控制，因为人类本身也不是世界的永久管理者。他主张：

对变革应保持开放态度，并试图让它变得更好。

对待 AI 应像养育子女一样，不应设定严格的目标（如 “必须解决癌症”），而应培养良好的价值观（如不伤害人类，帮助人类实现目标）。

AI 的应用应强调自愿性，确保人类始终拥有选择权，而不是被 AI 强制改变。
